01 / 选算法：先问这六件事

读完题先圈出对象、输出和约束。下面的流程用来缩小候选，不替代正确性证明；同一题也可能同时需要排序、双指针与去重。

  1. 选的是连续片段吗？子数组、子串必须连续。固定长度先想定长窗口；变长窗口先检查“右扩、左缩能否单向修复条件”。不连续的子序列通常需要动态规划；全排列、子集等显式输出所有方案通常需要回溯。
  2. 和的条件里有负数吗？正数区间的和随右扩不减，才支持典型的和阈值窗口；有负数时这个依据消失。问“和恰好为 K 的个数”优先前缀和加频次表；问最大连续和则考虑以当前位置结尾的动态规划。字符重复约束的窗口与数值正负无关。
  3. 数据有序，或判断结果具有单调性吗？有序数组查边界用二分；有序两数关系可以双指针。旋转数组不是全局有序，必须先识别有序半段。不要看到“最小”就二分答案：还要能写出单调可行性判定。
  4. 要求一个答案、全部方案，还是数量/最值？一个答案可能早停；全部方案需要保留路径并支付输出成本；数量可以合并等价状态；最值需要明确比较目标。路径不同但未来完全相同，才有机会用 DP 复用。
  5. 关系结构是什么？树的子问题多由孩子合成；无权图最短步数考虑 BFS；连通块可 DFS/BFS；有向依赖检测环考虑拓扑排序。带权图不能直接套普通 BFS。
  6. 规模容许多少工作？大数组先排除明显的双重枚举；小规模全方案接受指数复杂度。没有约束时先问，不用某个固定的“每秒运算次数”保证通过。
手工走一次：“和为 K 的子数组”要求连续、允许负数、输出数量。推导 prefix[j] - prefix[i] = K，于是查询历史前缀 prefix[j] - K 的出现次数。不是因为看到“子数组”就选窗口。

选定方法后反问：丢弃的信息为什么不会再有用？二分丢半边、窗口丢左端、贪心丢其他选择、DP 合并路径，分别需要不同的理由。说不出理由时，先保留朴素解，再找优化。

02 / 哈希：把“找搭档”变成查询

触发信号：无序查找、配对、分组、出现次数。先确定键保存“值、频次、下标、规范化结构”中的哪一种；问下标就不能只用集合。

不变量：扫描当前位置之前，表里只包含已处理元素。两数之和先查补数再插入，保证不会重复用当前元素。

步骤：把条件写成可查询的键；选择值的语义；遍历时先查询再更新。异位词分组用排序字符串或带分隔符的频次编码字符串作为键（int[] 默认按身份比较，不可直接作为值语义的键）；最长连续序列只从没有前驱的数开始向右延伸。

边界与反例：[3,3], target=6 是两个不同下标；先存后查可能用同一个 3 两次。连续序列如果从每个数都向后扫描，长连续数组会退化为平方时间。字典操作按平均常数时间估计，不等于排序键免费。

03 / 双指针：每次移动都要有排除依据

触发信号：有序数组配对、原地筛选、左右边界、快慢遍历。对撞指针依赖有序性或面积上界；同向指针常维护已完成前缀。

不变量：移动零时，写指针左侧是按原顺序保留的非零数；三数之和固定一个数后，左右指针之间包含尚未排除的配对。

步骤：先确定指针职责，再写移动条件。三数之和排序后，和偏小移左、偏大移右；命中后两端移动并跳过同值。盛水容器移动短板，因为保持短板只缩宽，不可能增大面积。

边界与反例：[-1,-1,2] 不能在所有位置无条件跳重复；只能按“同一枚举层”去重。排序会改变下标，不适用于要求原下标却未保存映射的版本。原地筛选不要一边遍历一边删除列表元素。

04 / 滑动窗口：维护一个可修复的区间

触发信号：连续片段、最长/最短长度、固定长度统计。先证明非法窗口能通过单向移动左端修复，且左端不必回退。

不变量：无重复子串在收缩结束后，窗口内每种字符最多出现一次；频次表与实际窗口严格一致。

步骤：加入右端；用 while 修复非法条件；在合法状态更新答案。固定长度异位词窗口则先限制长度，再比较频次。最长合法和最短满足条件的答案更新时机不同。

边界与反例：abba 加入第二个 b 后，左端要连续移动直到旧 b 被移走，不能只收缩一次。有负数的和窗口也不可靠：[4,-1], K=3 中先因 4 太大而删掉它，会错过后续和为 3 的区间。

模板 1 / 最长无重复子串
// 按 UTF-16 char 计数；补充平面字符需先转 codePoints。
static int longestUnique(String text) {
    // 只统计当前窗口内各字符的频次，不是整个字符串的累计频次。
    Map<Character, Integer> count = new HashMap<>();
    // 窗口左右端点均包含在内；answer 保存已经找到的最大合法长度。
    int left = 0, answer = 0;
    for (int right = 0; right < text.length(); right++) {
        char ch = text.charAt(right);
        // 右端新字符进入窗口；此前窗口合法，因此只可能是 ch 重复。
        count.put(ch, count.getOrDefault(ch, 0) + 1);
        // 必须持续收缩到合法，不能用 if：左移一步未必能移除重复字符。
        while (count.get(ch) > 1) {
            // 先取出旧左端字符，再移动左边界；下面同步减少它的频次。
            char old = text.charAt(left++);
            count.put(old, count.get(old) - 1);
        }
        // 修复后窗口内没有重复字符，此时才能用闭区间长度更新答案。
        answer = Math.max(answer, right - left + 1);
    }
    return answer;
}

左右端各走至多 n 步，嵌套循环仍是 O(n)。这里按 UTF-16 char 处理，辅助空间由已出现的不同 char 数决定；补充平面字符应使用 codePoints 并重新定义下标。

05 / 前缀聚合：区间变成两个边界

触发信号：连续区间和、和为某值的计数，或左右两部分可独立汇总。前缀和把重复求和变成差值；前后缀乘积则处理“除了自己”。

不变量：处理当前前缀之前，频次表记录所有更早的前缀和，包含空前缀 0。树上路径计数时，表只能记录当前祖先路径，不能混入兄弟分支。

步骤：累计前缀，查询 prefix-K，累加频次，再记录当前前缀。树上进入节点时加入，离开时撤销。乘积问题分别累计左右乘积，避免除法及零值问题。

边界与反例：[0,0], K=0 有 3 个非空子数组；集合会丢失重复前缀次数。忘记 count.put(0L, 1L) 会漏掉从下标 0 开始的解；先插入当前前缀再查询会把空区间算进去。

模板 2 / 和为 K 的子数组计数
static long countSubarrays(int[] nums, long k) {
    Map<Long, Long> count = new HashMap<>();
    // 空前缀出现一次，让从下标 0 开始、和为 k 的区间也能被统计。
    count.put(0L, 1L);
    // prefix 是当前前缀和，answer 是区间数量；用 long 降低整数溢出风险。
    long prefix = 0L, answer = 0L;
    for (int value : nums) {
        // 加入当前元素，得到截至当前位置的前缀和。
        prefix += value;
        // 区间和 = 当前前缀 - 历史前缀；寻找历史值 prefix-k 的出现次数。
        answer += count.getOrDefault(prefix - k, 0L);
        // 先查询再登记，避免 k=0 时把当前前缀和自己配对，误计空区间。
        count.put(prefix, count.getOrDefault(prefix, 0L) + 1L);
    }
    return answer;
}

06 / 二分：寻找边界，不猜等号

触发信号：有序位置、第一次满足条件，或能划分真假区间的单调谓词。

不变量：使用半开区间时，[0,left) 全部小于目标，[right,n) 全部大于等于目标；未知部分是 [left,right)。

步骤：先写区间定义；比较中点；排除已知一侧；结束后得到第一个大于等于目标的位置。精确查找还需检查下标合法且值相等。找末位置可用第一个严格大于目标的位置减一。

边界与反例：[2,2,2] 命中中点不等于找到左边界；目标比所有元素大时结果为 n，不能直接访问。旋转数组要分段判断，不能套普通全局有序模板。

模板 3 / lower_bound，返回值可能为 n
static int lowerBound(int[] nums, int target) {
    // 前提：数组非递减。维护左侧都 < target、右侧都 >= target。
    int lo = 0, hi = nums.length;
    // 在半开区间 [lo, hi) 中继续定位边界；相等时区间已空。
    while (lo < hi) {
        // 避免直接 (lo+hi)/2 的加法溢出。
        int mid = lo + (hi - lo) / 2;
        // mid 及其左侧都不满足条件，排除它们。
        if (nums[mid] < target) lo = mid + 1;
        // mid 可能就是第一个满足条件的位置，保留该边界。
        else hi = mid;
    }
    // 可能返回 nums.length；访问 nums[lo] 前必须先检查是否越界。
    return lo;
}

07 / 链表：先保存后继，再改连接

触发信号：原地重排节点、倒数位置、环和相交。先确认比较的是节点身份还是节点值。

不变量：反转时 prev 指向已反转前缀，cur 指向未处理后缀；快慢指针处理倒数位置时，两者保持固定间隔。

步骤：画出前驱、当前、后继三类引用；保存后继；重连；最后推进指针。删除或交换可能改变头节点时引入哑节点；环检测先相遇，再按入口算法重置一个指针。

08 / 树递归：返回值和全局答案分开

触发信号：左右子树可独立处理，当前节点再合并；尤其是高度、路径、祖先和合法性。

状态：先用一句话定义递归返回值。直径题返回“从当前节点向下的最大节点数”，全局答案记录“经过某节点的最大边数”。两者单位和用途不同。

步骤：定义空节点；递归孩子；更新当前候选；返回能被父节点继续使用的单支结果。验证搜索树则传递严格上下界，不能仅看直接孩子。

边界与反例：最长路径不一定经过根，不能只算根的左右高度。根 10 的左孩子 5 若有右孩子 12，局部父子比较可能通过，但它违反祖先上界。链状树递归深度是 O(n)，不是 O(log n)。

模板 4 / 直径按边数计
// 平台通常提供 TreeNode；独立运行时使用下面的定义。
static class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}
static int diameter(TreeNode root) {
    int[] best = {0}; // 每次调用重新初始化，避免跨测试残留。
    // 递归返回高度，全局数组单独记录直径，二者含义不能混淆。
    height(root, best);
    return best[0];
}
static int height(TreeNode node, int[] best) {
    // 空树高度为 0；本函数高度按节点数计算。
    if (node == null) return 0;
    int left = height(node.left, best);
    int right = height(node.right, best);
    // 经过当前节点的路径边数为左右子树高度之和，更新全树候选直径。
    best[0] = Math.max(best[0], left + right);
    // 向父节点只返回单侧最大高度，不能把分叉路径向上接。
    return 1 + Math.max(left, right);
}

09 / 图遍历：发现时标记，而非出队时

触发信号：连通块、网格扩散、最少步数、逐层结果。无权图中 BFS 首次发现距离最短，多源扩散应把所有源同时入队。

不变量：队列按非递减距离排列；已发现节点不重复入队。网格的上下左右是边，格子是节点。

步骤：初始化合法起点和 visited；取出节点；枚举邻居；边界与可通行性检查后立即标记并入队。按分钟计数时固定当前层长度，或直接存距离。

边界与反例：多个腐烂橘子不能逐个 BFS 后把时间相加；它们同时传播。visited 太晚更新会重复入队；仍有不可达新鲜橘子时应返回失败，而不是已遍历区域的最大时间。

模板 5 / 邻接表多源 BFS
static Map<Integer, Integer> distances(
        Map<Integer, List<Integer>> graph, Collection<Integer> sources) {
    Map<Integer, Integer> dist = new HashMap<>();
    Deque<Integer> queue = new ArrayDeque<>();
    // 多源 BFS：所有源点同时从距离 0 出发，相当于同一初始层。
    for (int source : sources) {
        // 源点去重并在入队时标记，避免重复扩展。
        if (dist.putIfAbsent(source, 0) == null) queue.offerLast(source);
    }
    while (!queue.isEmpty()) {
        int u = queue.pollFirst();
        for (int v : graph.getOrDefault(u, Collections.emptyList())) {
            // 已经发现的节点不再入队，避免环和重复路径。
            if (dist.containsKey(v)) continue;
            // 第一次发现 v 的距离，就是它到任意源点的最短边数。
            dist.put(v, dist.get(u) + 1);
            queue.offerLast(v);
        }
    }
    return dist;
}

10 / 回溯：路径、选择集合、撤销成对出现

触发信号：输出全部排列、组合、划分；约束可以在构造途中检查。

不变量：进入一层时 path 是合法前缀，used 或 start 准确描述剩余选择。回到父层时，状态必须与选择前一致。

步骤：确定终止条件；枚举当前层选择；剪掉不可能分支；选择、递归、撤销。子集用 start 避免顺序重复，排列用 used 禁止同一位置重复使用。

边界与反例：保存答案要复制路径，否则多个答案可能引用同一列表。组合总和允许复用当前候选，递归传 i；不能复用时传 i+1。剪枝依赖条件：只有候选为正数等前提下，剩余目标变负才可安全停止。

模板 6 / 输入元素互异的子集
static List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> answer = new ArrayList<>();
    subsetDfs(nums, 0, new ArrayList<>(), answer);
    return answer;
}
static void subsetDfs(int[] nums, int start, List<Integer> path,
        List<List<Integer>> answer) {
    // 必须复制路径；直接保存 path 会被后续撤销操作一起改掉。
    answer.add(new ArrayList<>(path));
    // start 以前的选择已决定；只从剩余后缀中继续选。
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        // 下一层只能选更后面的下标，每个子集只生成一次且不重复选同一元素。
        subsetDfs(nums, i + 1, path, answer);
        // 撤销本层最后加入的元素，让下一分支从同一状态出发。
        path.remove(path.size() - 1);
    }
}

12 / 背包：循环方向就是使用次数

触发信号：用一组数凑目标、每项可用一次或无限次；问可达性、方案数或最少数量。

状态：先区分 dp[s] 是能否达到和 s，还是达到它的最优代价。0/1 背包本轮只能读取上一轮结果；完全背包允许读取本轮较小容量结果。

步骤：零容量设为可达或代价 0；不可达设 false 或安全的极大哨兵值；逐项转移。每项一次时容量倒序，无限次时正序。计数还需区分顺序：先枚举物品通常计组合，先枚举总量可能计排列。

边界与反例：只有数字 2、目标 4，0/1 背包不应成功；正序更新却会在同一轮使用两次 2。零钱兑换无法凑出时不能返回无穷。模板假定数为非负整数；负数不能直接作为容量下标。

模板 7 / 非负整数，每个位置至多用一次
// 前提：target >= 0，且 nums 全部非负。
static boolean subsetSum(int[] nums, int target) {
    // dp[c] 表示：只使用已处理元素，能否选出总和恰好为 c 的子集。
    boolean[] dp = new boolean[target + 1];
    // 空集的和为 0，是所有可达状态的起点。
    dp[0] = true;
    for (int value : nums) {
        // 容量倒序：读取上一轮较小容量，防止同一元素在本轮被重复使用。
        for (int capacity = target; capacity >= value; capacity--) {
            // 不选当前元素，或从 capacity-value 的可达状态选入当前元素。
            dp[capacity] = dp[capacity] || dp[capacity - value];
        }
    }
    return dp[target];
}

14 / 栈：保存尚未解决的局部关系

触发信号：嵌套配对、回到最近未完成状态、下一个更大元素。普通栈维护语法层次，单调栈额外维护值的有序关系。

不变量：每日温度栈保存尚未找到更高温度的下标，温度从栈底到栈顶非递增。遇到更高温度时，可一次解决多个旧位置。

步骤：遍历当前位置；持续弹出已满足条件的栈顶并结算答案；最后入栈。括号匹配则遇左括号入栈、右括号核对栈顶。

边界与反例：[70,70,71] 中相等温度不能算“更高”；比较符号必须是严格小于。需要距离就存下标，不能只存温度。有效括号不只看数量，(] 数量相等仍不合法。

模板 8 / 下一个严格更大值的距离
static int[] nextGreaterDistance(int[] nums) {
    // 栈保存尚未找到答案的下标，所对应的值从栈底到栈顶非递增。
    Deque<Integer> stack = new ArrayDeque<>();
    // 默认 0 表示右侧没有严格更大的元素。
    int[] answer = new int[nums.length];
    for (int i = 0; i < nums.length; i++) {
        // 当前值解决所有比它小的栈顶；相等不弹出，因为要求严格更大。
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            // j 一直未被更早的位置解决，所以 i 就是它右侧首个更大位置。
            int j = stack.pop();
            // 保存下标距离，不是数值差。
            answer[j] = i - j;
        }
        // 当前下标等待后续元素解决；每个下标只入栈、出栈至多一次，总计 O(n)。
        stack.push(i);
    }
    return answer;
}

每个下标入栈、出栈至多一次，所以总时间 O(n)，不是按最坏内层次数直接乘 n。

15 / 堆：让当前最差候选容易被替换

触发信号：前 K、大量动态候选、只关心极值而不需要完整排序。

不变量：大小至多为 K 的最小堆保存扫描范围内最大的 K 个数，堆顶是其中最小值，即最容易淘汰的候选。

步骤：不足 K 时入堆；超过容量时弹最小值，或仅在新值更大时替换堆顶。前 K 高频先统计频次，再把频次作为比较依据。

16 / 贪心：证明局部选择不会缩小未来

触发信号：可用一个边界概括已完成决策，且局部最优有交换论证或覆盖支配关系。

18 / 易混对照：题目只改一个词，方法就变

窗口 vs 前缀和

窗口保存当前区间，靠单向修复条件；前缀和把区间映射到历史边界。无重复最长子串适合窗口；带负数的和为 K 计数适合前缀频次。前缀和本身不保证 O(n)，还需要高效找到对应历史前缀。

子串 / 子数组 vs 子序列

前者连续，后者只保持相对顺序。公共子串不匹配时对应连续长度归零；公共子序列不匹配时允许丢掉一侧元素，取两种前缀状态最大值。题目中的“连续”是方法选择条件，不是修饰语。

BFS vs DFS

BFS 按距离层推进，适合无权最短步数；DFS 沿分支深入，适合递归结构与连通性。两者遍历图都可 O(V+E)，不是 BFS 一定更快。BFS 空间取决于队列峰值，DFS 空间取决于栈深度。

回溯 vs DP

回溯保留路径差异以输出方案；DP 合并未来等价的状态以求最值或数量。记忆化的键必须包含影响未来的全部信息，例如单词搜索除了坐标还受已使用格子影响，只缓存坐标和字符位置通常不正确。

0/1 背包 vs 完全背包

关键是每个物品能否重复使用，不是数值是否重复。降维后倒序避免本轮重复，正序允许本轮复用。二维 DP 中应先明确依赖“上一行”还是“本行”，再推导循环方向，而不是死记箭头。

lower_bound vs 精确查找

前者总能返回插入边界，未找到也有答案；后者必须验证相等。上界是首个严格大于目标的位置，左右边界差才是重复次数。浮点数或非整数类型不要用“目标加一”冒充严格上界。

单调栈 vs 堆

单调栈解决带位置关系的最近更大/更小；堆解决候选集合的极值或前 K。每日温度需要“右边第一个更高”，不是整个后缀最高温度；堆顶最值并不直接给出最近的位置。

树高度 vs 树直径

高度是从当前节点向下的一条支路，父节点只能接一侧；直径允许左右两侧在当前节点汇合，不能作为同样的单支返回值继续向上传。先说明以节点还是边计数：单节点高度为 1、直径为 0 是这里的约定。

同层去重 vs 路径内防重

同层去重避免生成相同答案分支；used 防止当前路径重复用同一位置。组合和排列对元素顺序的定义不同。即便值相同，下标也可能是不同资源；先看题目允许的结果，再决定去重策略。

拓扑排序 vs 普通 visited

有向图访问过一个节点并不表示有环，两条分支可以汇合。检测环可用三色 DFS 判断是否回到当前递归路径，或逐步移除入度为零节点。课程表最终移除数不足总课程数才表明存在环；孤立课程也要计入总数。

19 / 复杂度与 Java：把隐藏成本算进去

先数状态，再数每个状态的工作

  • 双循环不一定平方。窗口和单调栈可用“每个元素最多进出一次”证明线性；反之，在 n 轮中复制数组区间、排序或用 List.contains 查找，可能把表面单循环变成平方或更慢。
  • 排序、堆与键构造。排序一般 O(n log n)；维护 K 个候选为 O(n log K)，建堆可 O(n)。异位词分组若每个字符串长 m，排序键还需 O(m log m)，不能只报 O(n)。
  • DP 看状态空间。两个长度 n、m 的前缀表一般 O(nm)；背包 O(n×目标值) 是伪多项式，目标数字很大时并不便宜。空间压缩不能改变依赖含义。
  • 全方案计入输出。n 个互异元素的子集有 2ⁿ 个，逐份复制需 O(n·2ⁿ)；全排列复制可达 O(n·n!)。辅助栈与答案占用分开报告，不能把保存的答案说成常数空间。
  • 树图计入栈和边。邻接表遍历 O(V+E)，树递归栈 O(h)，链状树 h=n。递归层数不是天然对数；网格 visited 最坏 O(行×列)。

提交前检查这些 Java 细节

  • ArrayList.remove(0) 会搬移后续元素，队列用 Deque<Integer> q = new ArrayDeque<>() 配合 offerLast / pollFirst；栈统一使用 push / pop / peek。ArrayDeque 不允许 null。List.contains 是线性扫描，HashSet 与 HashMap 查询通常按平均常数估计。
  • Arrays.copyOfRange(a, l, r) 与现代 Java 的 substring 都会复制区间内容；递归优先传下标。反复拼接字符串可能平方开销，循环内使用 StringBuilder.append，最后 toString()。
  • new int[n][m] 会创建独立的各行；不要把同一个 int[] 引用填入每一行。回溯用 new ArrayList<>(path) 保存快照，静态/实例可变字段在每次调用前重置，避免跨测试污染。二维数组复制通常只复制外层，需要逐行复制才是深拷贝。
  • 数组的长度是 a.length，字符串是 s.length()，集合是 list.size()。负下标与下标等于长度都会抛异常；二分返回 n、链表为空、矩阵为空都要显式处理。
  • Arrays.sort(a) 和 list.sort(comparator) 原地修改且返回 void，需要保留输入时先复制。不要在增强 for 遍历集合时直接增删结构，可用迭代器支持的 remove；HashMap / HashSet 不承诺迭代顺序。
  • 泛型参数用 Integer / Long / Character 等包装类型，不能写 List<int>。包装对象用 equals 比值，不能依赖 == 的缓存行为；节点身份判断才用 ==。HashMap 缺失键返回 null，自动拆箱可能空指针，计数可用 getOrDefault。数组键默认按身份比较，应编码为字符串或定义正确的 equals / hashCode。
  • String 不可变，内容相等用 equals；charAt 返回 UTF-16 代码单元，不保证等于完整 Unicode 字符。只有约束保证小写英文字母时才能安全使用 26 长度频次数组；一般 Unicode 需考虑 codePoints。
  • int 是 32 位，前缀和、乘积和计数可能溢出。先提升操作数：long product = (long) a * b，不能先做 int 乘法再赋给 long。比较器用 Integer.compare / Long.compare，避免 a-b 溢出；PriorityQueue 默认最小堆，最大堆可用 Comparator.reverseOrder()。
  • 深递归可能触发 StackOverflowError，长链与大连通块可改显式栈；用链状输入验证，而不只测平衡树。树栈 O(h)，并非总是 O(log n)。
  • 空解、无解、0、false、null 的语义要区分。最小化 DP 用安全哨兵并在转移前判断可达，避免对 Integer.MAX_VALUE 加一溢出；最后转成题目要求的返回值。输出下标、长度、节点、方案时保持返回类型一致。
